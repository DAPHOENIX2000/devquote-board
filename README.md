# 💬 DevQuote Board

An IDE-themed quote browser for developers. Quotes are displayed as JavaScript code in a full editor UI with syntax highlighting, reactions, and a daily challenge.

## ✨ Features
- **IDE interface** — Titlebar, file explorer, editor pane, status bar — just like VS Code
- **10 curated quotes** — From Fowler, Kernighan, Knuth, Torvalds, and more
- **Syntax highlighting** — Quotes rendered as actual JS code with keyword colors
- **Reactions** — React to quotes with 🔥 🤯 💯 (reactions persist locally)
- **Code snippets** — Each quote comes with a relevant code example
- **Search tab** — Search by author, tag, or keyword + filter by tag
- **Favourites** — Star quotes and view them in the favourites tab
- **Challenge of the Day** — A new coding challenge every visit
- **Dev Tip** — A random developer tip in the sidebar
- **File explorer** — Navigate quotes like files in a project

## 🚀 Live Demo
Enable GitHub Pages: **Settings → Pages → Branch: master → Save**

Then visit: `https://DAPHOENIX2000.github.io/devquote-board`

## 🛠 Tech Stack
- Pure HTML, CSS, JavaScript
- Google Fonts: JetBrains Mono, Inter
- Web Audio API (no external dependencies)

## 🎯 How to Use
1. Use **Next →** in the toolbar to browse quotes
2. Click hex codes in snippets to copy them
3. React with 🔥 🤯 💯 buttons
4. Switch to **search.js** tab to find quotes by keyword
5. Star quotes with ★ to save them to **favourites.js**
